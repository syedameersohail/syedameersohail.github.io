300,000 pipes scored by failure likelihood

PRISM — Proactive Infrastructure Risk Scoring Model

XGBoost ranking pipeline deployed on AWS SageMaker for Affinity Water. Scores every pipe in the network by burst probability. Built the scheme builder (v3) that converts risk scores into renewal investment plans using unit-rate cost lookups by surface type, diameter, and material. Optimisation uses benefit/cost ratio walk. Being used to compare AI-generated schemes against historically built schemes for director-level investment decisions.
